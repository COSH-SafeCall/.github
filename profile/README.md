# SafeCall

<img width="1672" height="941" alt="image" src="https://github.com/user-attachments/assets/15036437-7fc8-4c46-8da4-e1f791b0dfb5" />


> 불안한 이동 순간, 실제 가족이나 지인과 통화하는 것처럼 자연스러운 AI 안심 통화로 사용자의 대응 결정을 돕습니다.

SafeCall은 사용자가 불안한 귀갓길이나 이동 상황에서 현재 상황과 통화 상대를 선택해 실시간 AI 음성 통화를 시작할 수 있는 안전 보조 서비스입니다.

Gemini Live 기반의 자연스러운 음성 대화, 보호자에게 전달할 안심 메시지 작성, 긴급 호출 방법 안내를 하나의 흐름으로 연결합니다. SafeCall은 실제 신고나 구조를 대신하지 않으며, 사용자가 직접 다음 행동을 결정할 때까지 자연스러운 통화 상대와 필요한 안내를 제공하는 것을 목표로 합니다.

현재 조직에서는 React 기반 웹 MVP, Spring Boot API 서버 및 운영 인프라를 개발하고 있으며, 최종 제품은 React Native 기반 Android 앱으로 확장합니다.

---

## 01. 문제와 해결 방법

### 문제

늦은 귀가나 낯선 사람과의 마주침처럼 불안한 상황에서는 즉시 가족이나 지인에게 전화를 걸기 어렵거나, 현재 상황을 긴 문장으로 설명할 여유가 없을 수 있습니다.

일반적인 안전 서비스는 사용자가 직접 신고하거나 메시지를 보내는 행동에 집중되어 있어, 실제 대응을 결정하기 전까지 자연스럽게 주변에 통화 중인 것처럼 보이게 하는 수단은 제한적입니다. 또한 위치, 보호자 연락처, 긴급 호출 방법이 서로 분리되어 있으면 긴장한 상황에서 필요한 기능을 빠르게 찾기 어렵습니다.

### 해결 방법

SafeCall은 사용자가 네 가지 상황과 세 명의 통화 상대 중 하나를 선택하면, 선택한 맥락과 역할을 반영한 AI 안심 통화를 제공합니다.

사용자는 긴 문장을 입력하지 않고도 아빠, 엄마 또는 친구 역할의 AI와 자연스럽게 대화할 수 있습니다. 필요한 경우 등록된 보호자에게 보낼 안심 메시지와 현재 위치 링크를 준비할 수 있고, Android 긴급 호출 설정과 이용 방법도 확인할 수 있습니다.

AI는 위험도를 대신 판단하거나 112 신고와 안심 메시지 전송을 자동으로 수행하지 않습니다. 실제 문자 전송과 긴급 신고는 반드시 사용자가 직접 확인하고 실행합니다.

## 03. 주요 기능

### 카카오 로그인과 빠른 시작

카카오 OAuth를 이용해 사용자 계정을 연결하고 이름, 성별, 생년월일, 전화번호 등 서비스에 필요한 기본 정보를 확인합니다. 로그인 없이 빠르게 사용하기를 선택한 사용자는 계정 정보와 비상 연락망 없이 마이크 권한 확인 후 AI 안심 통화 기능을 이용할 수 있습니다.

### 상황과 통화 상대 선택

사용자는 다음 네 가지 상황 중 하나를 선택할 수 있습니다.

- 누군가 따라오는 것 같아요
- 택시 안이 불안해요
- 낯선 사람이 근처에 있어요
- 혼자 귀가하기 무서워요

통화 상대는 아빠, 엄마, 친구 중에서 선택합니다. 네 가지 상황과 세 가지 상대를 조합한 열두 개의 기본 페르소나를 기준으로 일관된 역할과 말투를 적용합니다.

### Gemini Live 기반 실시간 AI 안심 통화

클라이언트는 서버가 발급한 짧은 유효기간의 연결 정보를 사용해 Gemini Live와 연결합니다. 사용자의 음성을 작은 단위로 전송하고 AI 음성을 연속 재생하며, 사용자가 AI 발화 중 말을 시작하면 재생을 중단해 자연스러운 끼어들기를 지원합니다.

### 가상 수신 전화 경험

AI 연결이 준비되면 앱 안에 가상 수신 전화 화면을 표시합니다. 사용자가 전화를 받은 뒤 자연스럽게 첫 응답을 하면 선택한 통화 상대의 역할로 대화가 이어집니다. AI 연결에 실패하거나 통화 중 전환이 필요하면 앱에 포함된 대체 통화 음원을 이용할 수 있습니다.

### 홈 화면 빠른 시작

AI 안심 통화 시작 버튼을 짧게 누르면 일반 설정 흐름으로 이동합니다. 1초 동안 길게 누르면 버튼 주변의 상하좌우에 네 가지 상황이 나타나며, 원하는 방향으로 손가락을 이동한 뒤 떼어 해당 상황과 아빠 역할을 바로 선택할 수 있습니다.

### 보호자 안심 메시지 작성

등록된 보호자 최대 두 명을 수신자로 준비하고, 사용자 이름과 `010-xxxx-1234` 형식으로 마스킹한 전화번호를 메시지에 포함합니다. 위치를 확인할 수 있으면 현재 위도와 경도를 사용한 Naver 지도 링크를 추가합니다.

Android 앱에서는 문자앱 작성 화면을 열어 사용자가 수신자와 본문을 직접 확인한 뒤 전송합니다. 웹 MVP에서는 메시지 내용을 확인하고 복사할 수 있는 작성 화면을 제공합니다.

### Android 긴급 호출 안내

Android 전원 버튼 5회 긴급 호출 기능과 기기별 설정 방법을 안내합니다. SafeCall은 긴급전화를 자동으로 발신하지 않으며, 사용자가 긴급 호출 화면으로 이동하면 진행 중인 AI 통화와 연결 세션을 종료합니다.

### 개인정보 보호와 사용 기록 관리

음성 원문과 전체 대화 내용은 Spring Boot 서버에 저장하지 않습니다. 통화 상태, 처리 시간, 성공 여부 등 운영에 필요한 최소 정보만 기록하며, 사용자에게 비상 연락망 관리와 서비스 데이터 삭제 흐름을 제공합니다.

```text
   │  └─ 기본 정보 확인

            └─ 홈 화면
               ├─ 안심 통화 설정
               │  └─ 상황 선택
               │     └─ 통화 상대 선택

               │           └─ Gemini Live 연결
               │              └─ 가상 수신 전화
               │                 └─ AI 안심 통화
               ├─ 1초 길게 눌러 빠른 시작
               ├─ 안심 메시지 작성
               ├─ 긴급 호출 도움말
               └─ 사용자 설정
```

## 05. 핵심 설계 특징

### AI와 실제 기능의 역할 분리

Gemini Live는 선택한 상황과 통화 상대를 반영한 실시간 음성 대화만 담당합니다. 문자 작성, 위치 확인, 긴급 신고와 같은 실제 기능은 클라이언트와 운영체제가 담당하며, AI가 실행하지 않은 기능을 완료된 것처럼 안내하지 않도록 제한합니다.

### 열두 개 페르소나와 사용자 맥락 조합

서버는 네 가지 상황과 세 가지 통화 상대를 조합한 열두 개의 기본 프롬프트를 관리합니다. 카카오 로그인으로 나이와 성별이 확인된 경우에만 추가 지침을 결합하며, 로그인 없이 빠르게 사용하기 상태에서는 특정 나이와 성별을 전제하지 않습니다.

### 통화 세션과 연결 정보 보호

통화 세션은 생성, 준비, 수신 대기, 통화 중, 종료, 실패 상태로 구분합니다. 동일한 요청으로 세션이 중복 생성되지 않도록 멱등성을 적용하고, 단기 연결 정보는 사용하거나 만료되면 폐기합니다.

### 사용자 확인 중심의 안전 설계

안심 메시지는 사용자가 내용을 확인한 뒤 직접 전송하고, 긴급 신고도 Android 운영체제의 기능을 사용해 직접 실행합니다. SafeCall은 실제 문자 전송 완료 여부나 긴급 신고 완료 여부를 확정적으로 표시하지 않습니다.

### 최소 수집과 민감 정보 보호

사용자 정보와 비상 연락망은 서비스 제공에 필요한 범위에서만 저장합니다. 전화번호, 인증 정보와 연결 정보는 보호 조치를 적용하고, 운영 로그에는 음성 원문, 전체 대화, 전화번호 원문 및 불필요한 정밀 위치를 남기지 않습니다.

### 장애 상황을 고려한 대체 통화

AI 연결 상태와 관계없이 대체 통화로 전환할 수 있도록 클라이언트 자산에 통화 상대별 녹음본을 포함합니다. 대체 통화는 사용자의 말에 응답하는 양방향 AI 통화가 아니라는 점을 화면에 명확히 표시합니다.

### 자동 검증과 컨테이너 기반 배포

Spring Boot 서버는 단위 및 MySQL 통합 테스트를 분리해 검증합니다. GitHub Actions로 빌드와 테스트를 수행하고, 서버 이미지를 GitHub Container Registry에 게시한 뒤 AWS EC2의 Docker Compose와 Nginx 환경에 배포합니다.

## 06. 서비스 구성

### 인증 및 세션 서비스

카카오 OAuth 결과 또는 게스트 진입을 검증하고, SafeCall 사용자 계정과 웹 또는 기기 세션을 관리합니다. 세션 만료, 로그아웃, 요청 제한 및 중복 요청 방지 정책을 함께 적용합니다.

### 사용자 서비스

사용자 프로필, 권한 동의 상태, 비상 연락망과 사용자 설정을 조회하고 변경합니다. 비상 연락망은 보호자 최대 두 명까지 관리합니다.

### 통화 서비스

통화 세션을 생성하고 상황과 통화 상대에 맞는 프롬프트를 조합합니다. Gemini Live 단기 연결 정보를 발급하고, 통화 상태 변경과 종료를 관리합니다.

### 안심 메시지 서비스

사용자 이름, 마스킹된 전화번호, 등록된 보호자와 위치 링크 포함 여부를 기준으로 안심 메시지 작성 정보를 구성합니다.

### 홈 서비스

안심 메시지 작성 가능 여부, 위치 정보 포함 가능 여부와 통화 선택 항목 등 홈 화면에 필요한 상태를 제공합니다.

### 사용 기록 및 데이터 삭제 서비스

개인정보를 제외한 통화 사용 기록을 조회하고, 서비스 탈퇴 또는 동의 철회에 따른 데이터 삭제 작업의 상태를 관리합니다.

### 운영 관측 서비스

권한 결과, 통화 상태, 연결 성공과 실패, 처리 지연 등 장애 분석에 필요한 최소 운영 이벤트를 구조화해 기록합니다.

### 인프라 서비스

Docker Compose, Nginx, Let's Encrypt, AWS Secrets Manager와 배포 스크립트를 통해 HTTPS 기반 운영 환경과 비밀 정보 주입을 관리합니다.

## 11. 안전 원칙

- SafeCall은 실제 신고, 구조 기관 또는 보호자의 대응을 대신하지 않습니다.
- 즉각적인 위험이 있는 경우 AI 통화보다 112 긴급전화와 주변의 직접적인 도움을 우선해야 합니다.
- AI는 사용자의 위험도를 자동으로 판정하거나 신고와 메시지 전송을 대신 실행하지 않습니다.
